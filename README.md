# Olist_Customer_Segmentation_RFM_KMeans
This project aims to analyze customer behavior on the Olist Brazil e-commerce platform using two main segmentation approaches: RFM (Recency, Frequency, Monetary) and K-Means Clustering. The goal of this project is to help the business team better understand customer characteristics and develop more efficient and targeted marketing strategies.
